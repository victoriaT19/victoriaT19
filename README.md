### 🤖 AI Projects

| Project | What it shows | Tech |
| :--- | :--- | :--- |
| 🔍 **[tokenprof](https://github.com/victoriaT19/tokenprof)** | A token profiler for LLM agents. On 129 tasks with Gemma 4 agents, about 40% of prompt tokens were a prefix resent on every call; profiler-guided changes cut E2B's context overflows from 29% to 0%. [Paper on Kaggle](https://www.kaggle.com/competitions/gemma-4-developer-agent-paper/writeups/resolution-rate-is-not-enough-profiling-small-gem). | `Python`, `vLLM`, `LangGraph` |
| 🏁 **[f1-pit-wall](https://github.com/victoriaT19/f1-pit-wall)** | An F1 strategy engineer from public data: a whole-race simulation, finishing-order prediction with a Plackett-Luce ranking model (Spearman 0.705 vs. 0.677 for the grid) and a Gemma 4 agent with 10 tools (16/16 in its eval). [Live demo](https://huggingface.co/spaces/vtaua/f1-pit-wall). | `Python`, `Gradio`, `Tool calling` |
| ⚛️ **[resonance-physics](https://github.com/victoriaT19/resonance-physics)** | Gemma 4 E2B fine-tuned as a physics tutor and evaluated against the base model with an LLM judge: aggressive training made the physics worse (p = 0.049), the conservative run kept it. [Model](https://huggingface.co/vtaua/resonance-gemma4-physics) · [Demo](https://huggingface.co/spaces/vtaua/resonance-physics-demo). | `Unsloth`, `QLoRA`, `transformers` |
| 🦵 **[knee-report-labeler](https://github.com/victoriaT19/knee-report-labeler)** | An LLM reads 4,407 knee MRI reports and produces labels calibrated on 58 expert examples; the labels train an image model (AUC 0.828, RSNA on Kaggle). | `PyTorch`, `Qwen2.5`, `transformers` |
| 📷 **[Thermal Vision](https://github.com/aragao-a/Projeto-Infiray-Accenture-UFPE)** | Team project (Accenture–UFPE): YOLOv8 on an InfiRay thermal camera (mAP@0.5 of 0.91). I labelled the images and built the training set, worked on the YOLOv8 training, and wrote the thermal anomaly detector and the live app. | `Python`, `YOLOv8`, `Streamlit` |
